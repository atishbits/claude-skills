# html-slides notes

Copy to `data/notes.md`. The skill reads this at the start of every run and adds what it learns.
Personal: it stays in `data/` and its private cloud copy, never in git.

## Style

- Look: (e.g. "dark by default", "accent #0a7d5a", "no emoji icons")
- Length: (e.g. "8-10 slides unless I ask")
- Tone: (e.g. "plain words, one idea per slide")

## Sources I use

Where the files for recurring decks live, and which paths in them hold the figures. Example:

- Spending brief: the newest `analysis-*.json` in `<folder of the spending check-up>/data/skill-data/`;
  categories at `spending.by_category`, months at `spending.by_month`.
- Design decks: the skill folders under `<path to a code checkout>`.

## Decks

Anything worth remembering about past decks (what worked, what to change next time). The list of
decks and their links is in `skill-data/decks.json`; `python3 scripts/decks.py list` prints it.
